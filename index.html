安卓分享到拾光

安卓上网页没法直接出现在分享菜单里（需要 HTTPS），用开源的 HTTP Shortcuts 应用代替，设置一次就好：

  1. 在应用商店或 F-Droid 安装 HTTP Shortcuts（作者 Waboodoo）。
  2. 先在手机浏览器里打开一次本页，这样拾光能认出这台手机。
  3. 在应用里点 ＋ → Regular Shortcut，名字填「发送到拾光」。
  4. Basic Request Settings：Method 选 POST，URL 填：http://192.168.3.200:8088/api/add
  5. Request Body / Parameters：类型选 Custom Text，Content-Type 填 application/json，内容填下面这段，然后把 分享内容 换成变量（点输入框旁的 {} → 新建 Text 变量，在变量设置里勾选 Allow 'Share...'），把「我的安卓」改成你的手机名：
    {"text": "分享内容", "device": "我的安卓"}
  6. Trigger & Execution Settings 里打开 Show in Share menu（显示在分享菜单）。
  7. 以后在 B站、YouTube、浏览器等任意 App 里点 分享 → HTTP Shortcuts → 发送到拾光，就开始下载了。

点上面带框的文字可以复制。只能在家里的 Wi-Fi 下用。
