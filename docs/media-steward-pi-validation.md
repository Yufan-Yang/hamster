## 媒体管家完整链路

真实网页通过 HTTP 访问暂存应用，后台工人领取实际任务，使用合成音视频与字幕：

1. 打开页面不启动处理，初始自动补全关闭，隐藏内容不进入普通视图及计数。
2. 一次手动补全完成已有字幕导入、总结生成与产物验收，无需打开全库自动巡检。
3. 更新字幕后再次请求补全，关闭管理面板，后台仍继续更新总结并达到目标状态。
4. 开启后台巡检与 AI 排程后，自动推进新媒体；排序仅接受已核实的候选动作。
5. 暂停自动补全后，新增媒体不再自动派发。
6. 手机与桌面页面没有横向溢出，退出账号清除个人面板状态。

## 验收中修正的问题

- 将手动补全保存为有范围与期限的后台请求，避免字幕任务结束后丢失后续处理。
- 同时依据任务完成回执和资产状态继续复查，避免并发观察到旧的已达标产物时漏掉更新。
- 在后台处理期间持续刷新结果，并保留尚未保存的规则表单。
- 恢复常用搜索按钮的既定触控高度。
- 为 GNU tar 的隔离回滚测试补齐 gzip 命令，Git 仅在测试目录中提供。
