# 播放辅助 agents：取舍与验收

2026-11-15 对当前运行版本和真实媒体进行了只读检查。上一轮媒体任务均已完成，近期没有待修复事故，因此不增加重复的调度或修复入口。

本轮只上线两项有现成证据的能力：

1. **时间轴质检**：已发现 3 个章节、1 个要点的时间超出对应文件时长。质检器核对实际文件版本和探测时长，审查跳转，再生成可展示的时间轴。无效标记保留文字并取消跳转，不猜时间、不删除原始元数据。缺少可信时长时标为未核验，不伪称已修复。播放器也独立校验数值、分 P 和边界。
2. **续看回顾**：当前有 21 条未看完的知识类视频，其中 18 条已停留超过一天。回顾 agent 从上次停留点之前几分钟的字幕中选择少量有用原文；审查器逐条验证原文、来源及结束时间。界面显示可回看的摘录，不调用整片总结、不包含停留点之后的内容，也不声称停留点之前每段都已看过。影视、音乐、过短停留和缺乏证据时不自动生成。

暂不增加全库推荐、搜索 agent、自动导入未知文件或通用去重：已有相应入口或尚无证据证明能解决当前问题。

完整核验使用与文件当前修改时间一致的探测记录：858 条媒体中有 4 个越界跳转，另有 4 处正常但重复的章节时间点。重复项仅合并展示，保留所有标题，不计作失效跳转。续看候选经类型、至少两分钟停留和字幕边界审查后，有 19 条具备可用证据。

## 约束

- 后台准备遵守账号的自主处理开关。每个账号每天最多自动准备 3 份回顾，显式请求合计最多 6 份；相同输入复用，空结果与失败均占用额度，不循环重试。
- 回顾的时间边界在请求时固定；之后继续播放不能扩大它。暂停、进度清除、重看、换分 P、源文件/字幕变化、账号和隐私变化均重新核验。
- 仅使用受管文件、当前记录及其明确共享源。结果按账号保存，界面和接口实时校验所有权、隐私视图；API 不缓存，退出/锁定/关闭播放器同步清理。
- 不影响播放起点、已看状态、下载与原始总结；字幕摘录是单独产物。

## 上线门槛

- 用真实临时媒体验证越界跳转被阻止，文字和原始元数据保留；有效标记、分 P 和未知时长正常处理。
- 用真实 HTTP 和浏览器验证续看、引用回看、缓存、关闭/换号/隐私锁定与慢响应；模型输出模拟包含捏造、未来引用和重复内容的反例。
- 树莓派完整回归、生产数据库副本冒烟、版本/哈希/服务健康检查通过，录制服务保持运行。
- 生产先完整只读质检；真实回顾仅在已授权的自主处理账号内按预算生成，并核对引用时间边界与来源。
